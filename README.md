## 🧭 À propos

Je conçois des applications web et mobiles de bout en bout.De la modélisation
de base de données au déploiement en production, avec un intérêt particulier
pour les problématiques concrètes du contexte ouest-africain : mobile money,
marchés publics, accès à l'emploi.

Mon parcours d'enseignant m'a donné une vraie discipline pour décomposer des
problèmes complexes et documenter clairement mon travail, deux réflexes que
j'applique directement au développement logiciel.

- 🔭 Je travaille actuellement sur **FASOIA**, une plateforme IA pour l'emploi et les marchés publics
- 🌱 J'apprends en ce moment l'architecture Flutter avancée (Riverpod, Dio, Clean Architecture)
- 💬 Demandez-moi : Django REST Framework, architecture Flutter, intégration de modèles NLP
- ⚡ Fun fact : je code et j'enseigne les maths le même jour, souvent avec la même rigueur

## 🚀 Projets phares

### 🤖 [FASOIA](#) — Plateforme IA emploi & marchés publics
Plateforme complète associant un backend **Django REST Framework** et un
frontend **Flutter**, avec des moteurs de recommandation NLP hybrides
(**spaCy**, **Groq**, **Ollama**) pour le matching d'offres d'emploi et
l'agrégation de données de marchés publics (DGCMEF, UEMOA).

- Génération automatique de CV et lettres de motivation
- Tableaux de bord recruteurs, système de convocation de candidats
- Authentification JWT, déploiement en production (Render + Neon)

`Django` `DRF` `Flutter` `spaCy` `Groq` `Ollama` `PostgreSQL`

---

### 💰 [SoldeSync](#) — Suivi de transactions mobile money
Application de suivi de transactions mobile money développée en binôme :
backend Django REST Framework de mon côté, frontend Flutter développé par un
partenaire, collaboration à distance via Git.

- Trois profils utilisateurs (Particulier, Commerçant, Agent Mobile Money)
- Analyse de SMS transactionnels (patterns Orange Money)
- Architecture explorée pour la remontée de données sans API opérateur

`Django` `DRF` `PostgreSQL (Supabase)` `Flutter`

---

### 🧳 [FasoTour](#)
Projet de voyage/tourisme, avec containerisation complète de l'application.

- Docker & docker-compose pour l'environnement de développement
- Intégration Cloudinary pour la gestion des médias
- Remédiation de sécurité : purge de secrets exposés de l'historique Git

`Django` `Docker` `Cloudinary`

---

### 📐 [FasoMaths](#) — *🚧 En cours de conception*
Nouveau projet Flutter, actuellement en phase de démarrage, qui réutilise
l'architecture consolidée pendant ma montée en compétence Flutter
(modèle de données validé, client API avec intercepteurs, Repository,
gestion d'état Riverpod, gestion d'erreurs centralisée).

`Flutter` `Dio` `Riverpod`

---

### 📄 [DGCMEF Scraper](#) — Extraction de données de marchés publics
Outils de web scraping et d'extraction PDF pour les bulletins de marchés
publics du DGCMEF.

- Extraction structurée via `pdfplumber` et expressions régulières
- Commandes de gestion Django pour le scraping et l'analyse par lots

`Python` `Django` `pdfplumber`
